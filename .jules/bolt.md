## 2026-07-02 - Framer Motion High-Frequency Updates\n**Learning:** High-frequency event listeners (like mousemove) updating React state and animating layout properties (width/height) cause severe layout thrashing and continuous React re-renders.\n**Action:** Use Framer Motion's `useMotionValue` for state that updates rapidly to bypass React's render cycle, and animate `scale` instead of layout dimensions (width/height) for hardware-accelerated transforms without layout recalculation.
