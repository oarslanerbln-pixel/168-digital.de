## 2024-05-18 - Lazy Load Developer Tools
**Learning:** Large, conditionally rendered components (like `DevConsole` which is almost 500 lines long and imports heavy packages for cryptography or logging interfaces) can unnecessarily bloat the initial application bundle if statically imported, negatively impacting time-to-interactive for end-users who will likely never use them. Even if `isOpen` logic prevents immediate rendering, Webpack/Vite still includes the code in the primary chunk.
**Action:** Always dynamically import (`React.lazy()`) developer utilities and large modal overlays. Combine `React.lazy` with a `hasMounted` state flag to conditionally inject the `Suspense` tree into the DOM only after the user actively requests the tool, rather than solely relying on the component's internal `isOpen` props.
