## 2024-08-08 - Conditionally Rendering Suspense boundaries for Large Overlays
**Learning:** For large, modal-like developer tools (like `DevConsole`), wrapping a `React.lazy` component in a generic conditionally-rendered block (`{isOpen && <DevConsole />}`) can cause eager bundle fetching on the initial render if we're not careful. The bundler sees the `lazy` definition and may start fetching if the Suspense boundary is exposed, or the inner component may try to fetch chunks. Wait... actually, it's that just putting `<Suspense><DevConsole /></Suspense>` without conditional logic around `Suspense` causes React to render `Suspense` and start fetching `DevConsole` chunk, even if `isOpen` inside `DevConsole` is false and it returns `null` inside. We must gate the *entire* `Suspense` boundary behind a `hasMounted` flag.
**Action:** Always conditionally render the `<Suspense>` boundary itself with a `hasMounted` state flag to prevent the Vite bundler from eagerly fetching the chunk on initial load for utility overlays.
