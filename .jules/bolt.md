## 2024-05-19 - [Framer Motion Mousemove Performance]
**Learning:** Using React state to track high-frequency events like `mousemove` causes the component to re-render constantly. Framer motion provides `useMotionValue` and `useSpring` which update motion styles natively, bypassing the React render cycle, significantly improving UI framerates for dynamic components like custom cursors. Additionally, animating hardware-accelerated properties (like `scale`) rather than box model dimensions (like `width`/`height`) prevents browser layout thrashing.
**Action:** When creating high-frequency tracking components with Framer Motion, exclusively use `useMotionValue` and inject them directly into the `style` object of a `motion` component. Avoid animating box model constraints where `scale` will produce an identical visual outcome.
