## YYYY-MM-DD - AI Prompt Injection Vulnerability in Vercel Serverless Function
**Vulnerability:** The `api/chat.ts` serverless function allows the system prompt for the Gemini AI model to be overridden by a `customPrompt` parameter passed from the client-side (`req.body.customPrompt`). This allows any user to inject their own system instructions and completely control the behavior of the AI Representative. This is evident in `src/components/AIChatDrawer.tsx` which passes `localStorage.getItem('1618_ai_system_prompt')` to the API.
**Learning:** Client-provided parameters should never be trusted to dictate critical backend behavior, especially security-sensitive operations like defining AI system instructions. The system prompt is a form of access control and behavioral bounding for the AI model and must be strictly controlled server-side.
**Prevention:** Hardcode system prompts on the server side or load them from secure server-side configuration/environment variables. Never accept system-level instructions directly from unauthenticated client requests.
